# Тестовое задание снэпбилд

Развитие продуктового лендинга [снэпбилд](https://snapbuild.ru/) с сохранением
его визуального языка и добавлением пяти новых содержательных секций.

## Стек

- React 19
- TypeScript
- Vite

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка production-сборки

```bash
npm run build
npm run preview
```

## Публикация

Конфигурация Vite уже учитывает путь GitHub Pages
`/snapbuild-test-task/`. Workflow публикации и ссылка на опубликованную версию
будут добавлены после подключения GitHub Pages.

Остальные разделы README будут дополнены после реализации лендинга.
