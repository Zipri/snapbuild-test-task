# Тестовое задание Снэпбилд

Развитие продуктового лендинга [Снэпбилд](https://snapbuild.ru/) с сохранением
его визуального языка и добавлением пяти новых содержательных секций.

## Опубликованная версия

[https://zipri.github.io/snapbuild-test-task/](https://zipri.github.io/snapbuild-test-task/)

## Стек

- React 19;
- TypeScript;
- Vite;
- CSS Modules по секциям;
- GitHub Actions и GitHub Pages для публикации.

## Локальный запуск

```bash
npm install
npm run dev
```

Локальная версия будет доступна по адресу, который выведет Vite в терминале.

## Production-сборка

```bash
npm run build
npm run preview
```

## Добавленные секции

1. **Сценарии использования** — вкладки для маркетинга, дизайна, продаж и продукта.
2. **Этапы внедрения** — путь от аудита дизайн-системы до запуска команды.
3. **Интеграции** — варианты подключения систем и развёртывания в контуре компании.
4. **Тарифы** — планы подключения с переключателем ежемесячной и годовой оплаты.
5. **Форма обратной связи** — валидация полей и состояние успешной отправки без серверной части.

## Что воспроизведено

- Шапка с навигацией, мобильным меню и CTA.
- Первый экран, блок возможностей, продуктовые вкладки и сравнительная таблица.
- Блоки безопасности, дорожной карты, FAQ, финального CTA и footer.
- Характерные визуальные приёмы исходного сайта: тёмный фон, зелёный акцент,
  крупная типографика, тонкие границы, скруглённые контейнеры и карточные сетки.

## Анализ стилистики

Перед реализацией были изучены структура, типографика, цвета, сетка, отступы,
порядок блоков и интерактивные паттерны [исходного лендинга](https://snapbuild.ru/).
Новые секции встроены в существующую последовательность страницы и используют
те же акцентные цвета, типографическую иерархию, стили кнопок, карточек и границ.

## Ограничения и дальнейшие улучшения

- Форма демонстрирует клиентскую валидацию и не отправляет данные на сервер.
- При дополнительном времени можно подключить API для заявок, добавить аналитику
  событий и провести расширенное визуальное тестирование в браузерах.

## Использованные AI-инструменты

Cursor использовался для анализа исходного лендинга, подготовки структуры
React-компонентов, написания стилей, проверки адаптивности и технической
доработки проекта. Результат проверялся и корректировался вручную.
